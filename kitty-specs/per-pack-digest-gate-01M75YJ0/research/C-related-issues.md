## Proposed mission scope

Mission "Per-pack digest gate for the built-in level": give every pack with `pack_level: built-in` (found from `pack.yaml`, not a hardcoded list; today seven, not just foundation and writing) a recorded `snapshot_sha256` tree digest, enforced by one check in the required `Validate packs gate`. Reuse a single digest helper for the docsite provenance block. Add tests, including a failing case for a built-in-level pack with no digest. Rename the CI step, script and comments to say what they cover. Close #182 as done (cite 53df95d), file the two residual manifest gaps, and fold in a new "docs build as a required check" issue. Link #190 (add #194 as a child), #23 and #19, and note #124 progress.

Out of scope: #124, #37, #195, core fetch alignment (charter-only policy), the full #23 trust model and `checksums.json`, #5 java extraction.

Open question: one `.source.yaml` with an entry per pack, or `packs/<pack>.source.yaml` each? Core reads `packs/built-in.source.yaml`, so keep that file's schema intact for `built-in`.
