# Plan (caveman)

Same plan step as software-dev. Decisions stated outcome-first; rationale kept, padding cut.

## Voice (CAVE_001)

- Each decision: what, then why, in that order. One line where one line does.
- Paths, module names, commands: exact.
- Trade-offs and risks: plain sentences, no hedging fog.
- Keep negations — "do not touch X" is a decision.

## Do

1. Write `plan.md`: architecture, data flow, the decisions and their reasons, the risks.
2. State each decision outcome-first; keep the reasoning, drop the narration.
3. Name what is out of scope.

Output: `plan.md` — decisions outcome-first, exact references.
